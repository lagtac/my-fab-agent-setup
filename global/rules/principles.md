# Universal principles

- Do only what was asked. Keep changes minimal and tightly scoped. The one exception is a reported fault: fix every instance in the files you were asked to change.
- Never fabricate. If you cannot verify something, or a step fails, say so and do not guess.
- Before you create anything new, search the repository, the docs, the notes, and the installed tools for an existing solution.
- Match the style, naming, and file structure that already exist. Apply the writing rules to any prose you add.
- Do not duplicate information across files. Link to the source instead.
- Keep notes and docs as current state, not a changelog. Commit messages and pull request text are exempt.
